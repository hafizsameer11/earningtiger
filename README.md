# Earning Tigers

Online job opportunity platform with user registration, payment receipt upload, and PHP admin panel.

## Setup

```bash
cd d:\projects\new-erning
php -S localhost:8000
```

1. Open http://localhost:8000/install.php once
2. Visit http://localhost:8000/
3. Admin: http://localhost:8000/admin/login.php (admin / admin123)

## Admin Panel

- **Dashboard** — Stats and recent registrations
- **Registrations** — Approve/reject, view receipts
- **Payment Methods** — JazzCash, EasyPaisa details
- **Site Settings** — Edit all content, images, salaries
